# Oas — A Little Universe Made for You ✨

A mobile-first, interactive birthday website themed around Oas's love for MS Dhoni and devotion to Shri Krishna.

## Features
- Cinematic night-sky / gold theme and responsive layout
- Optional original synthesized background melody (Web Audio API; no copyrighted song)
- Interactive birthday candle and wish moment
- Mini cricket game with runs, balls, boundaries and sound effects
- Krishna-inspired blessing moment
- Tap-to-bloom bouquet
- Openable birthday letter and confetti finale
- Replay button and small navigation menu

## Put it on GitHub Pages
1. Create a public GitHub repository, e.g. `oas-birthday`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` into the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main`, folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/oas-birthday/`.

No build step, framework, or paid hosting is required.

## Music note
The site creates a gentle, original instrumental melody in the browser. Browsers require a user tap before audio can start, so Oas can turn music on with the **Music off** button. It is not a recording of a commercial song.

## Personalize further
Edit the birthday note in the `#letterCard` section of `index.html`. You can change Oas's name, message, or visual copy directly in that file. The site uses no secret server-side data; it is a static site.


## Birthday note tone
The letter is written for a close female friend who is especially meaningful to the sender: warm, sincere and affectionate without assuming a romantic relationship.
